# La Notte di Valentina — publicación

ZIP preparado para publicación del proyecto. Las 7 fotografías originales están restauradas en `public/images/` con los nombres que usa la aplicación.

Incluye `public/whatsapp-preview.jpg`, una carátula horizontal 16:9 creada colocando la fotografía original sin retoque generativo.

`index.html` incluye metadatos Open Graph/Twitter apuntando a `/whatsapp-preview.jpg`.

La vista previa de WhatsApp solo aparecerá cuando el sitio esté publicado en una URL pública que permita a WhatsApp rastrear `index.html` y la imagen.
